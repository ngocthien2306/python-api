# Test Commands for Chat Endpoint

## 1. Test Audio Service Health
curl http://localhost:3000/health

## 2. Test Python API Health  
curl http://localhost:8000/docs

## 3. Login (get token first)
curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d @sample_data/login_request.json

## 4. Test Basic Chat (replace YOUR_TOKEN with actual token)
curl -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d @sample_data/chat_basic.json

## 5. Test Task Creation Chat
